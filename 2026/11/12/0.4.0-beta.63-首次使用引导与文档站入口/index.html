0.4.0-beta.63：首次使用引导与文档站入口

首次使用的入口重做了一遍：工作区网格按钮上先出现一次性圆点与锚定气泡，进去后是「一句说明 + 三个动作」的引导卡；插件详情第一层也多了一张文档卡片。三处都能直达文档站，同一批还补了四处就地提示。数据侧没有迁移，DOC_VERSION 仍是 1。

摘要

① 首启提示只出现一次：圆点角标 + 锚定气泡，关闭写入 dsh-session-grove.entry.v1，从按钮或气泡主行动进入视图同样失效。
② 引导卡改为「一句说明 + 新建分组 / 使用文档 / 知道了」，树为空时它就是空状态。
③ 设置页顶部新增文档卡片；视图选项、状态浮层、会话分叉、分组归档各补一行就地提示。
④ 无数据迁移：DOC_VERSION 仍为 1、无新字段；语言资源 385 → 397 键。

改了什么

这一版把「第一次用」拆成入口提示、引导卡、设置页三段入口，再给四个容易误解的地方各补一句话。

  • 首启提示：入口按钮加圆点角标，锚定气泡只出现一次。
  • 不动官方数据：气泡里写明工作区归属和日志都不变。
  • 文档直链：气泡、引导卡与设置页共用同一个文档站地址。
  • 行动优先引导卡：一句说明之后是新建分组、使用文档、知道了。
  • 真正的空状态：树为空时它就是空状态，有数据时留在顶部。
  • 设置页文档卡：详情第一层最上方是标题、一句说明、打开文档。
  • 四处就地提示：视图选项、状态浮层、会话分叉、分组归档各一行。
  • 无迁移：DOC_VERSION 仍为 1，只多一个浏览器本地键。

注意

圆点、气泡与引导卡都是一次性的：点「不再提示」「知道了」，或从入口按钮、气泡主行动进入视图后，都不会再自动出现；「使用文档」只是打开新标签，不会收起提示。

展开：首启提示的锚定、失效与文案

  • 圆点角标与气泡都挂在插件自己插入标题行的固定按钮上，不读取宿主 DOM 节点。
  • 气泡默认落在按钮下方，靠近视口底部时翻到按钮上方；左右按视口夹取，RTL 下同样处理，不会跑出屏幕。
  • 关闭气泡（「不再提示」）、点主行动「进去看看」，或直接点入口按钮进入视图，都会写入 dsh-session-grove.entry.v1。
  • 已写入时安装只渲染按钮本身：不画圆点、不建气泡；文档站入口仍在引导卡与设置页。
  • 提示状态每次工作区模式安装只读一次，文案取当时的界面语言；宿主没有「首次启动」插槽，入口按钮是插件唯一能合法出现的首启位置。

怎么用

1. 第一次看到入口上的圆点

  1. 装好并重启 DSH Desktop，回到官方工作区视图。
  2. 「工作区」标题行右侧的网格按钮右上角多一个圆点，旁边浮出气泡。
  3. 气泡标题是「自由分组已就绪」，正文说明它把不同工作区的会话收进同一分组，官方工作区归属和日志都不变。
  4. 点「进去看看」直接进入自由分组视图；点「不再提示」只收起提示，按钮仍在。
  5. 气泡里的「使用文档」直接指向本站，首启那一刻就能打开。

这一步在官方视图里等提示自己出现，下图是网格按钮上的圆点与锚定气泡。

2. 用引导卡完成第一次建组

  1. 第一次进入自由分组视图；树为空时，引导卡直接替代原来的空状态。
  2. 卡片标题是「自由分组」，正文只讲这一层是什么，下面三个动作。
  3. 点「新建分组」，输入名称后确定，卡片同时收起并记住。
  4. 点「使用文档」直达本站看完整教程，卡片不会收起；点「知道了」同样收起并记住。
  5. 已有分组时，同一张卡留在列表顶部作为紧凑提示；归档筛选造成的空列表仍用原来的空状态与按钮。

这一步从引导卡完成第一次建组，下图是三个动作与下方的会话列表。

3. 从设置页打开文档

  1. 在 DSH 左侧栏点「插件」，进入「自由分组」（包名 dsh-session-grove）详情。
  2. 第一层最上方是文档卡片：标题「使用文档」、一句说明与「打开文档站点」。
  3. 文档卡是普通链接，配置表单不可用时也能点开。
  4. 打开的是本站的教程总览，安装、分组、配置、搜索、AI 控制与数据备份都在里面。

这一步从插件详情进文档站，下图是设置页最上方的文档卡片。

4. 四处就地提示

  1. 视图选项：两段归档三态下面多一行「筛选只影响显示；归档分组会锁定其结构，但不会归档其中的会话。」
  2. 状态浮层：「执行中、待介入、未读三态互斥，不含后台任务。」
  3. 会话菜单的「分叉会话」行：悬停提示「以最后一个已完成轮次分叉；新会话放到源会话所在分组顶部。」
  4. 分组菜单的「归档分组」行：悬停提示「锁定此分组的结构；其中的会话仍可打开。」
  5. 归档锁定行仍显示各自的禁用原因，不会被这行通用提示覆盖。

这一步先看视图选项里的那行说明，另外三处在各自的菜单与浮层里。

升级说明

  • 数据：DOC_VERSION 仍是 1，没有新字段，也没有迁移脚本；旧文档直接可读，回退到 .62 也不会破坏数据。
  • 本地键：唯一新增的持久化是浏览器本地键 dsh-session-grove.entry.v1；清掉它，下次加载会重新显示首启提示。
  • 语言资源：19 种词典从 385 键补到 397 键，新增 12 个键，onboarding 标题与正文改写、文档键改指本站；npm test 继续校验结构对齐。
  • README：插件仓 README 精简为落地页（是什么、安装、快速开始、功能概览、数据与配置、限制、开发、链接），长文使用教程搬到本站；docs/INDEX.md 把用户文档（本站）与维护者文档（仓库）分开。
  • QQ 群：群二维码从插件仓移出，改放本站；本站总览页底部的「交流群」就是入口。
注意

插件内三个文档入口都指向同一个文档站；首启提示关闭后没有「重新显示」按钮，想再核对入口位置，看安装与 60 秒上手的第 2 步。
