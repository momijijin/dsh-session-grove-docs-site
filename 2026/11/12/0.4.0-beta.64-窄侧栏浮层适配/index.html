0.4.0-beta.64：窄侧栏浮层适配

这一版只改显示层：三个状态浮层、视图选项、配置浮层，加上行菜单和拖拽浮标，统一改用视口坐标定位。侧栏太窄时不再硬贴按钮一侧，而是翻到另一侧；窗口太矮时按剩余空间限高，内容多就在面板内滚动。头部紧凑态也改由实测宽度驱动，264–300px 下标题整段隐藏，320px 起恢复。

摘要

① 五个浮层统一按视口定位：优先贴按钮同侧，放不下翻边，再放不下才夹取；高度按剩余空间算，超高时面板内滚动。
② 264px 侧栏下状态浮层向右翻边、完整可见；默认宽度下也不会再被宿主裁掉左侧。
③ 紧凑头部按实测宽度切换（约侧栏 390px）：264–300px 标题整段隐藏，320px 起恢复，320→340 的「加宽反而更糟」消失。
④ 行菜单宽度 ≤ min(360px, 视口−16px)，拖拽浮标 ≤ min(280px, 视口−44px)，长文案单行省略号 + 悬停全名。
⑤ 无数据与语言契约变化：DOC_VERSION 1、397 键不变、无新持久化字段。

改了什么

  • 一套定位模型：浮层改 fixed + 视口坐标，逻辑边优先，越界翻边，仍越界才夹取；高度按触发器上下剩余空间计算。
  • 不再被宿主裁切：面板不再依赖 CSS 左右边锚，宿主侧栏上的 overflow: hidden 裁不到它；264px 与默认宽度下都能完整显示。
  • 短窗口可滚动：内容超过可用高度时在面板内滚动，视图选项、状态列表和配置列表共用同一套限高。
  • 紧凑头部：data-narrow 改由实测根容器宽度驱动（377/385 滞回）；标题由永不隐藏的标题容器可用宽驱动，容不下才整段隐藏。
  • 菜单与浮标：行菜单有宽度上限并在超长时内部滚动，菜单项单行省略号 + title；拖拽浮标离开窗口会被夹回。
  • 关闭回焦：三个状态按钮、视图选项与配置 chevron 五个触发器关闭后，焦点回到触发按钮。
  • RTL：按逻辑边解析，RTL 下镜像，不再用 CSS 物理左右覆盖。

注意

窄态可能隐藏标题文字、计数为 0 的数字与会话行的工作区名，隐藏的不是数据；标题的悬停提示与读屏名称仍在。状态面板外框比上一版窄 10px，属预期变化。

展开：浮层怎么选边、限高与降级

  • 选边：按面板最近的 [dir] 解析逻辑边（inline-end / inline-start），LTR 贴触发器右侧，RTL 镜像；首选边越界就翻到另一侧。
  • 夹取：翻边后仍越界才在视口内夹取，左右各留 8px；正常路径不会把面板贴死在屏幕边缘。
  • 限高：maxHeight = 视口高 − 8px − 面板顶部；下方放不下且上方放得下时改到上方，上下都放不下才贴顶并给整屏高度。
  • 外框：宽度按 border-box 测量，回写不会因 padding 或 border 每轮变宽；两段测量在同一帧完成，首屏不跳。
  • 降级：宿主若用 transform / filter 重新包含 fixed 元素，打开时会做四角命中自检；失败则收进最近裁剪祖先并标记 data-fallback="clip"，面板仍可用。
  • 范围：三个状态浮层、视图选项、配置浮层、行菜单与拖拽浮标；对话框原本就按视口夹取，不在这次改动里。

怎么用

1. 窄侧栏点状态按钮

  1. 把侧栏拖到 264px，或任意窄到放不下面板的宽度。
  2. 点标题行的执行中 / 等待用户介入 / 未读任一按钮。
  3. 面板优先贴按钮同侧；侧栏放不下时向右展开到内容区，四边完整可见，不再只剩半截文字。
  4. 点条目打开会话；按 Esc 或点外部关闭，焦点回到刚才那个按钮。

这一步把同一场景放在一起对比：左侧旧版被宿主裁成一条，右侧新版向右翻边。

2. 短窗口或高 DPI 打开视图选项

  1. 把窗口拉矮，或把系统缩放调到 125% / 150%；等效 CSS 视口会变小。
  2. 点标题行的视图选项（滑杆图标）。
  3. 面板高度按按钮下方剩余空间计算，底部不再越出窗口；内容超高时在面板内滚动，两段三态仍可连续设置。
  4. 配置浮层和状态浮层同理；面板会优先翻到空间更多的一侧。

这一步在 1440×480 的短窗口里对比：左侧旧版底部被窗口截断，右侧新版完整落在窗口内并可滚动。

3. 窄侧栏的标题行

  1. 侧栏窄到约 390px 以下进入紧凑态：按钮间距收紧，计数为 0 的数字隐藏，给标题让出宽度。
  2. 264–300px 时标题可用宽度不足，整段隐藏，只留图标与按钮；会话行的工作区名也一并隐藏。
  3. 拉回到约 320px，标题恢复完整；再拉宽到约 390px 以上退出紧凑态。
  4. 标题的悬停提示与读屏名称仍是完整名称；隐藏的只是屏幕上的文字。

这一步在 264px 侧栏下对比标题行：旧版标题只剩一个字符残片，新版整段隐藏，按钮全部留在侧栏内。

4. 行菜单与拖拽浮标

  1. 在窄窗口打开组菜单或会话菜单：宽度最多 min(360px, 视口宽度 − 16px)，超长项单行省略号，悬停看全名。
  2. 项目多或窗口矮时菜单内部滚动，不会顶出窗口。
  3. 拖动会话时，跟随指针的浮标不会跑出窗口；长名称最多 min(280px, 视口宽度 − 44px)，超出部分单行省略。

5. 关闭后焦点回到按钮

  1. 打开任意一个头部浮层，按 Esc 或点外部关闭。
  2. Tab 焦点回到刚才的触发按钮，而不是落到页面开头。
  3. 三个状态按钮、视图选项与配置 chevron 都走这条路径；行菜单原本就有自己的焦点返回。

升级说明

  • 数据：DOC_VERSION 仍是 1，没有新字段、迁移或新持久化偏好；回退到 .63 直接读同一份文档。
  • 语言：19 种词典 397 个键不变，没有新增文案；长标签复用现有文案的 title。
  • 外观变化：状态面板外框 258 → 248（窄 10px）；紧凑态阈值从侧栏 320px 改为约 390px，320–380px 的侧栏会开始隐藏 0 计数与工作区名，264–300px 才隐藏标题；视图选项浮层会按内容展开到最多 360px，比上一版更宽。
  • 验证：隔离实例的窄视口矩阵 30 格全过（含 RTL、短视口与长名菜单），语言门禁 23/23；官方 A+ 本批未重跑，最新证据仍是 .61。
