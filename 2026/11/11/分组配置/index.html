分组配置

当前适用版本：0.4.0-beta.64

分组配置（profile）是一份命名的分组方案：同一批会话可以有多套分组树、归档组与折叠状态，切换只决定当前显示哪一份。入口在「自由分组」标题旁的 chevron，切换前会先给一份只读差异预览；当前配置是全局的，多窗口跟随同一个 active。

摘要

① chevron 打开配置浮层；当前配置带勾选，每行显示「N 组 · M 会话」。
② 选中另一套配置先弹只读差异预览；内容相同则直接切换。
③ 另存为/管理在浮层底部，重命名/归档在「管理配置…」里；未归档上限 20 份。
④ 切换成功后有 5 秒撤销；active 全局一致。

打开配置浮层

1. 从标题旁的 chevron 进入

  1. 在「自由分组」标题右侧点 chevron。
  2. 浮层列出所有未归档配置：当前行带勾选并加粗，第二行是「N 组 · M 会话」。窄侧栏下浮层会翻到另一侧；配置名过长时单行省略号，悬停看全名；短窗口下列表在浮层内滚动。
  3. 默认配置在列表里显示为 default，命名配置显示保存时填的名称。
  4. 底部是「另存为新配置…」和「管理配置…」。

这一步打开配置浮层，示例里有 default、工作配置、测试配置三套。

切换前先看差异

2. 只读差异预览

  1. 在浮层里点另一套配置；两套内容不同时，先弹出「切换到「X」」预览。
  2. 顶部三个计数：分组、会话、未分组，都是「当前 → 目标」。
  3. 「分组」段列出新增（+）、移除（−）、变更（~，归档状态翻转时带「归档状态已变更」）与「顺序变化」。
  4. 「会话」段列出换组（旧路径 → 新路径）、新归组、回到未分组与失效引用。
  5. 核对「N 个会话将回到未分组」提示；预览全程只读，取消不改任何数据。
  6. 勾选「以后直接切换」可跳过预览；点「切换到此配置」才真正切换。

这一步在切换前核对两套配置的差异，下图以 default 切到工作配置为例。

注意

预览不写盘；切换不复制、不改写、不删除会话。预览若已过期（例如另一窗口刚改过配置），确认按钮会禁用并提示重新选择目标配置。

另存、重命名与归档

3. 另存为新配置

  1. 浮层底部点「另存为新配置…」。
  2. 名称 1–40 个字符，不能与已有的未归档配置重名；默认预填「<当前名> 副本」。
  3. 下方提示「将复制当前配置：N 组 · M 会话」。
  4. 点「创建」后新配置立刻成为当前配置；另存为成功后只提示成功，不提供撤销，5 秒撤销只在切换配置成功后出现。

这一步以当前配置为模板复制一份。

4. 在「管理配置…」里重命名与归档

  1. 浮层底部点「管理配置…」；顶部显示「N/20」。
  2. 每行有「重命名」「归档」；当前配置、default 与最后一份未归档配置不能归档。
  3. 归档只把配置从切换列表隐藏，文档、备份与会话都保留；归档行在弹窗里只读显示「已归档」。
  4. 底部「以后直接切换」与预览弹窗里的同名开关等价。

这一步在管理弹窗里整理已有配置。

注意

未归档配置最多 20 份（含 default）。达到上限后「另存为新配置…」不可用，悬停提示「最多 20 份配置」；需要先归档不再使用的配置腾出位置。

5. 切换后的 5 秒撤销

  1. 切换成功后底部出现「已切换到「X」」。
  2. 5 秒内点「撤销」回到上一套配置；超时后提示消失，需要重新切换。
  3. 撤销也会走一次预览与激活；失败时保留当前配置并给出提示。
  4. 另一个窗口切换配置时，本窗口提示「另一窗口已切换到「X」」并跟随重载。

这一步在切换成功后回退，下图是 toast 与撤销入口。

展开：当前配置为什么是全局的

  • activeId 存在配置注册表里，所有窗口读同一个值；切换后通过 SSE 广播 active 事件。
  • 每个窗口收到后重载目标配置的分组文档，并重置本地视图状态（搜索、拖拽、折叠选择等）。
  • 一次切换只更新注册表里的 activeId，不改写任何配置文档。
  • 归档只写 archivedAt 标记；界面不提供恢复按钮，需要恢复时按 README 的数据说明手动处理注册表。
