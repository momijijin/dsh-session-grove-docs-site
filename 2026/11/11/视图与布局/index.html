视图与布局

当前适用版本：0.4.0-beta.62

自由分组视图有一套自己的布局：侧栏宽度、分组展开状态、视图模式和弹窗位置都会保存在本地，重开 DSH 还是你离开时的样子。视图切换靠标题行那个网格按钮；想把侧栏调宽，拖右缘的把手，双击它回到默认的 420。视图选项里的「恢复默认显示」只重置布局，不动分组数据。

摘要

① 网格按钮在官方工作区视图与自由分组视图之间切换，选择会被记住。
② 侧栏宽度范围是 264px 到窗口宽度的 80%，默认 420px；双击把手复位。
③ 展开/折叠按分组配置记住；「恢复默认显示」重置宽度、展开状态与弹窗位置。

切换视图

1. 在两个视图之间来回

  1. 在官方工作区视图点「工作区」标题行的网格按钮，进入自由分组视图。
  2. 在自由分组视图，同一个按钮的提示变成「返回默认工作区视图」，点它切回。
  3. 关闭 DSH 再打开，会回到上次停留的视图，而不是每次都从工作区开始。
  4. 两个视图共用同一批会话；切换只改变侧栏显示哪一层，不改会话归属。

视图选项

2. 打开视图选项

  1. 点标题行右侧的「视图选项」按钮（滑杆图标）。
  2. 「会话」段设置会话归档三态：隐藏已归档 / 全部对话（显示已归档）/ 仅显示已归档。
  3. 「分组」段设置分组归档三态，与会话段互不影响。
  4. 选中后浮层保持打开，方便一次设置两段；点空白处或按 Esc 关闭。
  5. 点「恢复默认显示」，宽度、分组展开状态和弹窗位置一起回到默认，底部提示「显示布局已恢复默认」。

这一步把入口和选项放在一起看，下图红框①是切回工作区的网格按钮，②是视图选项浮层，③是恢复默认显示。

注意

「恢复默认显示」只重置侧栏宽度、分组展开状态和弹窗位置；不会删除或调整分组、分组归属或工作区配置。

宽度与折叠

3. 拖动侧栏宽度

  1. 把指针移到侧栏右缘的窄条上，指针变成左右箭头。
  2. 按住拖动：最窄 264px，默认 420px，最宽到窗口宽度的 80%。
  3. 双击把手，宽度立即回到默认的 420px。
  4. 宽度应用后保存在本地，切回工作区视图也不会跳回宿主默认值。

4. 展开与折叠分组

  1. 点组头，或点组头左侧的箭头，折叠该组。
  2. 折叠后只保留组头、组名与会话数。
  3. 折叠状态按分组配置分别保存，切换配置不会串。
  4. 折叠只影响显示；组内会话仍在，展开即恢复，官方状态与分组归属不变。

这一步把侧栏拖宽到 600px，并折叠了「产品设计」，下图红框①是宽度把手，②是折叠后的组头。

布局会记住什么

偏好 行为 「恢复默认显示」
视图模式 记住上次所在视图 不重置
侧栏宽度 264px 到窗口 80%，默认 420px 重置为 420px
分组展开 按分组配置分别保存 全部展开
弹窗位置与尺寸 按对话框类型记住 清除
归档筛选 会话、分组两套各自记住 不重置

展开：这些偏好存在哪

  • 视图模式：dsh-session-grove.view.v1，只有 groups / workspace 两种值。
  • 侧栏宽度：dsh-session-grove.width.v1，数值按窗口宽度重新夹取。
  • 折叠状态：dsh-session-grove.collapsed.v1，值形如 {[profileId]: {[groupId]: true}}，旧的扁平值按默认配置读取。
  • 归档筛选：会话用 dsh-session-grove.archive.v1，分组用 dsh-session-grove.archive.groups.v1。
  • 弹窗几何：dsh-session-grove.dialog.geometry.v9，恢复默认显示时清除。
