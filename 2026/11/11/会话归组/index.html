会话归组

当前适用版本：0.4.0-beta.65

分组只改变会话在自由分组视图里的位置：同一个分组可以放来自不同工作区的会话，归组本身不改官方工作区、会话日志与 workspace.json。除了拖进拖出，把鼠标移到会话行上会出现归档按钮；会话菜单里的分叉与复制 Session ID 也都从同一行进入。

摘要

① 从任意工作区把会话拖进分组，行上会显示工作区名；拖回「未归组」即退出分组。
② 组头 + 新建的会话使用推断工作区；首次发消息前切换工作区仍留在原组。
③ 把鼠标移到会话行上可归档/取消归档；会话菜单可分叉会话、复制 Session ID，分叉落在源会话所在分组顶部。

归组与移出

1. 把不同工作区的会话拖进同一个分组

  1. 在自由分组视图按住任意会话行，拖到目标分组上松手，组头提示「放入『X』」。
  2. 指向组内任意一行，右侧会显示它的官方工作区名；不同工作区的行可以并排放在同一组。侧栏进入紧凑态时这行工作区名会隐藏，会话行的悬停提示里仍带工作区名。
  3. 拖动组头可以排序或改成子组；拖动会话行可以在同组内调整顺序。
  4. 组头的会话计数随归组、移出即时更新，未归组计数同步减少。
  5. 拖动时跟随指针的浮标不会跑出窗口；长名称最多占 min(280px, 视口宽度 − 44px)，超出部分单行省略。

这一步看归组后的结果：JustTool 的会话与原本只有 CosineVoiceProjects 会话的行并排放在「会话侧栏」组里。

2. 把会话移出分组

  1. 把会话行拖到「未归组」标题或列表区域，提示「移出分组，放到这里」后松手。
  2. 也可以打开会话菜单 →「归入分组…」，在弹窗里选「未归组」。
  3. 未归组列表按最近活动排序；移出只改分组归属，不归档、不删除会话。
  4. 归档分组的结构是只读的，拖出与归入都会先被拒绝，需要先取消归档。

这一步用「归入分组…」弹窗完成同样的移出与换组。

3. 在分组里新建会话

  1. 指向组头，点右侧 +；或打开组菜单选「新建会话」。
  2. 工作区按组内已有会话推断：组里只有一种工作区就用它，混杂时用当前会话的工作区，空组用当前工作区。
  3. 空白会话出现在组内会话的第一位，并成为当前会话。
  4. 首次发消息前切换工作区，空白会话仍会跟回该组；发送首条消息、手动移组、分组被删或保存失败后，跟随结束。

这一步在「日常事务」组内新建会话，组计数从 3 变成 4。

注意

组内新建只决定「放在哪个组」和「用哪个工作区」；真正创建工作区、切换工作区仍由官方侧栏完成。归档分组不能新建会话，菜单项会说明结构只读。

行操作与会话菜单

4. 把鼠标移到会话行上：归档与取消归档

  1. 指向任意会话行，右侧出现归档图标；点它归档该会话。
  2. 归档后行变暗并显示「已归档」，同一位置的图标变成取消归档；再点一下恢复。
  3. 需要看到已归档行时，在视图选项把会话筛选切到「全部对话（显示已归档）」或「仅显示已归档」。
  4. 这两个按钮只调用宿主的归档能力，不改变会话的分组归属。

这一步在「全部对话」筛选下把焦点移到一行已归档会话上，悬停或键盘聚焦都会显示行操作。

注意

归档正在运行的会话会先弹确认；选「停止并归档」才会停止活动。归档不是删除，日志仍在，之后可以取消归档。

5. 会话菜单：分叉与复制 Session ID

  1. 打开行尾的 … 菜单，里面有重命名、分叉会话、归档、复制 Session ID、归入分组…、上移/下移。
  2. 菜单打开时，滚动右侧会话区（包括流式输出的自动滚动）不会关闭它；滚动左侧分组树、点外部、按 Esc 或改变窗口尺寸才关闭。
  3. 「分叉会话」的悬停提示写明「以最后一个已完成轮次分叉；新会话放到源会话所在分组顶部」，成功后的子会话就落在源会话所在分组的顶部。
  4. 源会话未归组时，子会话不写入分组文档，按最近活动出现在未归组列表顶部。
  5. 「复制 Session ID」把完整 ID 写入剪贴板，并提示「Session ID 已复制」。
  6. 归档分组内的会话不能分叉或移动，菜单项会说明原因；打开、改名、切换自身归档与复制 ID 仍可用。

这一步在一个归组会话上打开菜单，分叉与复制 ID 都在这里。

分叉成功后，子会话直接落在源会话所在分组的顶部。

展开：归档分组里的会话还能做什么

  • 打开（自身未归档时）、重命名、切换自身归档状态、复制 Session ID。
  • 拖拽、上移/下移、归入分组、分叉被禁用，提示「归档分组内不能移动或分叉」。
  • 分叉点取最后一个已完成轮次；没有已完成轮次或没有权限时，提示不能分叉。
  • 归档不会级联修改组内会话的归档状态；组里的会话仍可单独归档或取消归档。

下一步

  • 分组配置：多套命名配置之间切换，先看只读差异再确认。
  • 搜索与筛选：按标题、工作区或分组路径找会话，并处理归档结果。
