0.4.0-beta.61：模块拆分与测试加固

这是一个纯内部重构版本：没有新增功能，也没有界面结构变化，公共 API、存储格式、语言资源与可见交互都不动。唯一可见差异是一条失败 toast 的文案，其余改动都在模块边界与测试里。

摘要

① plugin.js 从约 1300 行降到约 400 行，配置界面、弹窗、宿主契约、视图状态按职责拆开。
② 单元/契约 699 → 726，UI 运行时 39/39，覆盖率 93.94/85.42/90.34。
③ 无 API/存储/语言资源变化；唯一可见差异是「取消归档」失败 toast 的文案。

改了什么

拆分围绕「谁拥有状态、谁只做组合」展开，依赖方向保持 document ← profiles ← host，注入的运行时桥接键一个不少。

  • 客户端组合根瘦身：插件入口只保留组合根职责，体量大幅下降。
  • 配置界面拆分：配置列表、差异预览与切换流程各自独立成模块。
  • 配置弹窗独立：配置相关弹窗从外壳拆出，其余弹窗仍留在外壳。
  • 宿主契约拆分：宿主契约按 HTTP 原语、响应与配置策略分开。
  • 视图状态收口：视图状态按持久化与外部变更分文件，导入方无需改动。
  • 常量唯一出处：配置数量与名称长度上限只留一处定义，既有导入照旧可用。
  • 显示名校验：显示名校验与重名检查集中一处，由两处调用共用。
  • CSS 不拆：样式产物字节数与上一版相同，规则顺序不变。
对比项 旧版（0.4.0-beta.60） 新版（0.4.0-beta.61）
plugin.js 约 1300 行 约 400 行
配置界面 单个 components-profiles.js switcher / preview / switch 三个模块
配置弹窗 配置逻辑在 dialog-host.js 独立 dialog-profile.js
宿主契约 单个 route-contract.js wire / respond / policy 三个模块
单元/契约测试 699 条 726 条
CSS 单个文件 字节数与上一版相同

展开：拆分后的模块边界

  • 客户端：入口 src/client/plugin.js 从约 1300 行降到约 400 行，只保留组合根职责；文档读写与串行提交移到 plugin-document.js；配置领域（列表刷新、预览、激活、新建/重命名/归档、被动切换提示）移到 plugin-profiles.js；插槽、宿主动作、弹窗编排与挂载接线移到 plugin-host.js。可变状态跟随写入它的控制器。
  • 配置界面：components-profiles.js 拆成 profile-switcher.js、profile-preview.js、profile-switch.js，预览偏好存储移到 profile-storage.js；profile-switcher.js 负责标题旁 chevron、浮层、恢复条，profile-preview.js 负责差异正文与预览底栏。
  • 切换与公开名：profile-switch.js 负责预览 → 激活 → 撤销/恢复；模块图无环，两个预览判定只在 profile-switch.js 定义一次、由 profile-preview.js 再导出，公开模块名不变。
  • 配置弹窗：dialog-host.js 中配置相关的一半移到 dialog-profile.js，后者负责另存为/重命名/管理/归档的正文、客户端名称校验、底栏动作与写入提交；外壳只按 dialog.kind 分发，并保留焦点陷阱、几何、键盘、关闭/Escape；DialogHost 的 props 未变，分组/会话弹窗正文仍留在外壳。
  • 宿主契约：route-contract.js 拆成 http/wire.js、http/respond.js 与 profile-policy.js；http/wire.js 含 HTTP 原语与请求体解析（含配置路由共用的 readJsonBody），http/respond.js 是冻结的响应形状；旧单存储适配器移到 legacy-profile-manager.js。
  • 配置策略与桥接：profile-policy.js 负责配置作用域的 plan hash、控制目标解析、doctor 存储报告、预览令牌与显示名策略；routes.js 的再导出桥接被移除。
  • 视图状态：state.js 变成桶文件，下挂 state/persistence.js 与 state/external-change.js；createStore 仍留在 state.js，既有导入方无需改动；state/persistence.js 管 localStorage 键、安全访问、读写与折叠表归一化，state/external-change.js 管 SSE revision/active 路由。
  • 共享常量与显示名校验：shared/profile-limits.js 是 MAX_PROFILES（20）与 MAX_PROFILE_NAME（40）的唯一出处，host/constants.js 为既有宿主导入方再导出；shared/profile-name.js 收拢显示名校验与大小写不敏感重名检查，供 profile-registry.js 与 profile-policy.js 共用。
  • 去重与边界：四个客户端兜底字面量改为引用共享常量；/commit、/diagnostics 与控制路由保留各自的有界读取器和原有错误码。
  • CSS：六个候选域在文件中并不连续（配置片段含引导/空状态，弹窗片段含运行中会话动作、toast、侧栏轨道、设置表单），按候选顺序拼接会改变字节序列；按单一职责拆需约 11 个连续片段，收益不足，规则顺序不变。

测试变化

功能不动，测试补的是边界；下面按层级看结果。

  • 单元/契约：699 → 726 条，全部通过、0 跳过；新增 12 条存储序列化/降级写入、6 条控制接口幂等/降级/按路由状态矩阵、9 条配置注册表损坏/降级用例；这批测试没有改动生产代码。
  • UI 运行时：39/39（1 条模块加载 + 38 条组件测试，覆盖 17 个组件）；模块加载 smoke 覆盖 24 个客户端模块，profile-storage/profile-switcher/profile-preview/profile-switch 取代旧的 components-profiles。
  • 浏览器几何：新增 5 条真实几何断言：弹窗宽 ≥ 560px、高度落在 DialogHost 上下限内；正文 scrollHeight > clientHeight 且 overflow-y: auto、有滚动轨道、程序化 scrollTop 生效。
  • 排版与窄侧栏：长变更标题/路径换行不产生横向溢出；相邻变更行间距极差 ≤ 1px；最窄侧栏布局（宿主轨道 264px，社区隔离宿主插件根 252px、官方宿主 256px）下弹窗仍在视口内。
  • 覆盖率：93.94% 行 / 85.42% 分支 / 90.34% 函数（门槛 92/80/85）；store.js 85.99%、control-routes.js 88.20%、profile-registry.js 89.11%。
  • 隔离宿主证据（2026-11-10）：社区与官方隔离宿主的 test:isolated、test:ui-browser 均通过，test:locale-pack 与 test:all-locales 23/23 通过；语言资源仍为 331 键，无依赖变化、无数据迁移。

怎么用

本版没有新增操作步骤，升级后照原样使用即可。

1. 照旧升级后继续使用

  1. 正常升级即可。
  2. 继续用原有入口拖动、归组、切换配置。
注意

本版唯一可见差异是「取消归档」失败时的 toast 文案：现在显示「取消归档失败」，不再露出 toast.unarchiveFailed 这样的原始 i18n 键。重命名失败路径不受影响。

展开：为什么只有这条 toast 变了

createActions 原来在模块加载时创建，那时翻译器还是恒等函数，失败提示会直接显示原始 i18n 键；现在改为挂载后创建，真实翻译器已就位。

重命名失败路径不受影响（它的 toast 一直来自带翻译器的弹窗处理器）。这是对既有错误提示的顺手修正，不是新功能，也不改变任何 API/UX 契约。

兼容性

公共 API、DOC_VERSION 1 的存储格式、HTTP 路由与错误码、语言资源键都没有变化。

  • 升级或回退本版不需要迁移数据。
  • 已有配置、分组或会话的存放位置不变。

内部改动

展开：依赖方向与公开边界

重构后的依赖方向是 document ← profiles ← host：文档读写与串行提交在最底层，配置领域建立在文档之上，宿主接线只做编排；可变状态跟随写入它的控制器。公开模块名与 DialogHost 的 props 未变，两个预览判定仍只在 profile-switch.js 定义一次、由 profile-preview.js 再导出。
